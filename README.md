# Ayoub Mouchtak — Full-Stack Angular Portfolio

An enterprise-grade, high-converting personal portfolio web application built with **Angular 21+** to showcase web application development capabilities to high-paying clients.

---

## 🚀 Key Features

- **4 Flagship Showcase Projects**:
  1. **EliteCare**: Healthcare & Telemedicine Clinic Portal (Desktop & Mobile view)
  2. **PowerFit**: High-Performance Gym & Membership Subscription Platform (Dark mode + Lime)
  3. **Vanguard Law**: Corporate & Civil Litigation Law Firm Portal (Hero & Attorney Directory)
  4. **L''Élixir**: Luxury Gastronomy & Curated Signature Dish Ordering Experience
- **Interactive Deep-Dive Case Studies**:
  - Modal with challenge, architectural solution, tech stack, key features, and measurable business outcomes.
- **Dynamic Category Filters**:
  - `All Projects`, `Healthcare & MedTech`, `Fitness & Sports`, `Corporate & Legal`, `Luxury & Dining`.
- **Full-Stack Competencies Matrix**:
  - Frontend (Angular, TypeScript, Tailwind, PrimeNG), Backend (Spring Boot, .NET, REST, Stripe), and Databases (MySQL, PostgreSQL, SQL Server).
- **Client Conversion & Direct Inquiry**:
  - Quick consultation inquiry modal, direct contact form, and clean consultation booking actions.

## 💻 How to Run Locally

```bash
# 1. Navigate to the project directory
cd "portfolio-angular"

# 2. Run the Angular development server
npm start
# or: ng serve
```

Then open `http://localhost:4200` in your web browser.

---

## 🌐 How to Deploy (Free in 2 Minutes)

### Option 1: Vercel (Recommended)
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and import your repo.
3. Framework Preset: **Angular**. Output Directory: `dist/portfolio-angular/browser`.
4. Click **Deploy**.

### Option 2: GitHub Pages
```bash
npx angular-cli-ghpages --dir=dist/portfolio-angular/browser
```

### Option 3: Netlify
Drop the folder `dist/portfolio-angular/browser` into the Netlify manual deploy dropzone.
